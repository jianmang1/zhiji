## 1. 产品定位
- **一句话**：执己是一款 **C 端上架**的「XX王人格化 + 新粗野主义」微信小程序，用游戏化评分 + 多 AI 意见，帮用户"先知己，再执己"。
- **形态**：微信小程序（Taro 4 编译，同源出 H5 网页）；**C 端上架分发**（非自用工具）。
- **Slogan**：先知己，再执己。
- **价值主张（Why not 备忘录/记账App）**：
  - 把抽象"自我记录"变成有反馈、有态度的**"王"养成游戏**——即时评分给认知反馈，LLM 给可执行规划。
  - v1 聚焦三大生活主轴（**身体 / 搞钱 / 异性交往**），**做深做透再扩展**，而非铺五个半吊子。

## 2. 目标用户（C 端画像草案）
- 关注自我提升、愿意记录生活的年轻人（约 18–35 岁）。
- 对身材管理 / 搞钱 / 异性交往有诉求，但讨厌被说教、偏好张扬反叛的表达。
- 对"精致 ins 风"审美疲劳，被粗野 / 梗文化吸引。

## 3. 核心闭环
```
采集（打卡某王热点，手动）
   → 沉淀（结构化 events，按王归属 domain+type）
   → 评分（规则引擎算该王评分，即时反馈）
   → 看板（三王评分总览 + 趋势）
   → AI 意见（generatePlan 调 LLM 生成可执行规划）
   → 执行反馈（次日再打卡，形成循环）
```

## 5. 评分系统
- 每个王**独立评分（0–100）**，由**规则引擎**计算（不依赖 LLM，稳定、即时、零成本）。
- **算在何处**：前端实时算（打卡即见反馈），云函数/服务端作为权威存分并供看板聚合。
- **公式（🟡建议值，待 PO 确认）**：各指标按"周聚合"，单项得分 = `min(实际 / 满分阈值, 1) × 权重 × 100`，加总即该王周评分。

|---|---|---|---|
| 薄肌王 | 饮水 ml | ≥2000 | 30% |
| | 睡眠 h | ≥49(7×7) | 30% |
| | 训练 min | ≥210(30×7) | 40% |
| 力王 | 工作时间 h | ≥40 | 35% |
| | 工资(元，周) | ≥预期薪资/4 | 35% |

## 8. 用户旅程（关键路径）
1. 微信授权登录（`cloud.auth`）。
2. 首页看板：三王评分总览 + 今日待打卡。
3. 点某王 → 打卡页（手动录入该王热点数值）→ **即时评分反馈**。
4. 看板趋势 + AI 意见卡（generatePlan）。
5. 执行 → 次日再打卡，形成闭环。

## 15. 增长漏斗与精细化数据分析框架（产品深度 · 演进路线）

> PO 诉求（2026-10-20）：从"记录工具"演进为**可计算、可视化、可定位瓶颈**的精细化增长系统，支撑五大价值——①定位流失瓶颈（哪步流失最多）②评估渠道质量（不同渠道用户质量）③发现体验问题（加载慢/流程复杂）④指导 A/B 测试（验证优化）⑤支持精细化运营（按渠道/地域/用户类型拆分）。

### 15.1 两层漏斗模型（核心结构）· 2026-10-22 重构（见 ADR-007）

> **ADR-007 裁定（2026-10-22）**：保留漏斗可视化；产品级 AARRR **改名「王败寇」**（社交证明向）；薄肌王漏斗以**「自己体感 1–10 分」为最终层**；**砍掉分群运营页**；力王/黄毛王漏斗**暂保留现有不动**。王败寇社区人数为**占位数字**（不实做跨用户聚合，ADR-006 隐私冻结维持）。

**① 产品级「王败寇」（原 AARRR 改名 · 社交证明向）**
目的：让用户看到"有多少人在记录数据"。五层（基于 `product.*` 步骤映射）：

| 新层名 | 映射步骤 | 进入阈值 |
|---|---|---|
| L1 陌生人 | `product.acquire` | 进站 / 首触（base） |
| L2 好奇猫 | `product.activate` | 初步激活（完成首次打卡） |
| L3 留存 | `product.retain`/`product.habit` | **记录数据天数 > 3** |
| L4 落魄谷 | `product.habit`（深化） | **记录数据天数 > 10** |
| L5 少年归 | `product.value`（漏斗到底） | **漏斗到达底部次数 > 10** |

- `召回/复活(reactive)`：保留为沉默用户重激活的计数，但不作为独立展示层。

**② 各王行为漏斗（瓶颈定位 · 长期累积）**
| 王 | 行为漏斗（v1/当前） |
|---|---|
| 黄毛王 | 启动→首触(approach)→**破冰(response)**→约见(date)→进阶(stage_up)→脱单(stage5)→推荐（**本次暂保留**） |
| 薄肌王 | **L1 喝大水+睡大觉 → L2 运动 → L3 压抑指标(suppression, 越低越好) → L4 体感(feel_score 1–10, 最终目的)**（基于真实 `events`，ADR-007 重构） |
| 力王 | 启动→收入(工资)→支出(消费)→留存→推荐（**本次暂保留**） |

> 薄肌王漏斗基于真实打卡 `events`（water/sleep/workout/suppression/body_sense），各层记录真实数据、长期累积；王败寇仍基于 `analytics_events`（`product.*` 步骤）。分群运营页已砍（ADR-007）。

### 15.2 指标分层（五类问题指标）
按 PO 五大价值目标分类：
- **A. 流失瓶颈诊断**：单步转化率、单步流失率(drop-off%)、**瓶颈步(=drop-off 最大步)**、整体漏斗转化率、沉默用户占比、**复活率**。
- **B. 渠道质量**：各渠道获客量、**各渠道激活率**、**各渠道 D7 留存**、各渠道人均价值(打卡数/段位)、**渠道质量分**(激活×留存×价值加权)、CAC(若付费)、自然量 vs 付费量。
- **C. 产品体验**：页面加载 P50/P95(ms)、**打卡完成时长(s)**、**步骤内放弃率**、各屏错误率、崩溃率、表单字段回填率、重访中断率。
- **D. A/B 测试支撑**：实验分组曝光、**实验转化率提升(lift)**、显著性(p/CI)、**守护指标**(retention 不下降才放过)。
- **E. 精细分群**：按 渠道 / 地域 / 用户类型 / 偏好王 / 段位(青铜~王者) / 获客周(cohort) 拆分上述所有指标。
- **各王专项**：黄毛王=破冰率/约会转化率/脱单率/线上vs线下搭讪质量；薄肌王=三件套完成率/体脂测量率/达标率/体脂方向；力王=储蓄率/享乐占比(反比)/工资趋势/财务健康分。
- **北极星+复合**（§10）：日打卡率、7日留存、**周活跃王数**(本周碰了几个王)、综合健康分、K因子。

| 王 | v1 漏斗步骤（现在做） | 合并/移除说明 | Phase 3 才做 |
|---|---|---|---|
| 黄毛王 | 启动→首触→破冰→约见→进阶→脱单→推荐 | 全用已定义事件类型(approach/date/chat/stage)，零额外摩擦；破冰=approach 的 `got_response` 字段 | 渠道搭讪质量对比、脱单率趋势看板 |

- 产品级 v1：获取→激活→留存→习惯→推荐；`召回/复活` 顺带埋。
