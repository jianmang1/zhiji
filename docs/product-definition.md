## 1. 产品定位
- **一句话**：执己是一款 **C 端上架**的「XX王人格化 + 新粗野主义」微信小程序，用游戏化评分 + 多 AI 意见，帮用户"先知己，再执己"。
- **形态**：微信小程序（Taro 4 编译，同源出 H5 网页）；**C 端上架分发**（非自用工具）。
- **Slogan**：先知己，再执己。
- **价值主张（Why not 备忘录/记账App）**：
  - 把抽象"自我记录"变成有反馈、有态度的**"王"养成游戏**——即时评分给认知反馈，LLM 给可执行规划。
  - v1 聚焦三大生活主轴（**身体 / 搞钱 / 异性交往**），**做深做透再扩展**，而非铺五个半吊子。

## 2. 目标用户（C 端画像草案）
- 关注自我提升、愿意记录生活的年轻人（约 18–35 岁）。
- 对身材管理 / 搞钱 / 异性交往有诉求，但讨厌被说教、偏好张扬反叛的表达。
- 对"精致 ins 风"审美疲劳，被粗野 / 梗文化吸引。

## 3. 核心闭环
```
采集（打卡某王热点，手动）
   → 沉淀（结构化 events，按王归属 domain+type）
   → 评分（规则引擎算该王评分，即时反馈）
   → 看板（三王评分总览 + 趋势）
   → AI 意见（generatePlan 调 LLM 生成可执行规划）
   → 执行反馈（次日再打卡，形成循环）
```

## 4. 三王映射（v1 范围，做透）
| 域(domain) | 王(主题) | 热点(type)与评分维度 | 状态 |
|---|---|---|---|
| `health` | **薄肌王** | 喝大水(饮水 ml)、睡大觉(睡眠 h)、练薄肌(训练 min) | ✅ 已定 |
| `work` | **力王** | 工作时间(h)、工资(元)、通勤时间(min) | ✅ 已定 |
| `dating` | **黄毛王** | 异性交往维度：TODO 热点（如主动搭讪 / 约会次数 / 聊天时长 / 脱单进度） | 维度已定，热点待细 |

- **v1 仅此三王**。`consumption`（消费）维度**已取消**；`capability`（能力）/ `interest`（兴趣）v1 不做，数据模型预留扩展（契约 domain 枚举后续加）。
- "做透"含义：每王评分规则精细、AI 意见有深度、粗野视觉人格化到位，而非匆匆铺多个半成品。
- 每个"王"是生活维度的**主宰者隐喻**：评分 = 你在这片疆域的"统治力"。产品深度来自此隐喻（呼应"从认知到执行"）。

## 5. 评分系统
- 每个王**独立评分**（0–100 或等级制），由**规则引擎**计算（不依赖 LLM，稳定、即时、零成本）。
- 维度映射示例：睡大觉 ≥7h 满分、喝大水 ≥2000ml 满分、练薄肌 ≥30min 满分；力王按工时/工资/通勤规则；黄毛王按异性交往热点规则（TODO）。
- **算在何处**：前端实时算（打卡即见反馈），云函数/服务端作为权威存分并供看板聚合。*TODO 与技术契约对齐（见 §13）。*
- 等级命名（如 青铜王/黄金王？）TODO 由 PO 定。

## 6. AI 意见（多 AI 分析）
- **看板 + LLM 生成 plan**：`generatePlan` 云函数 v1 上线（Codex 已实现骨架，需接云端 LLM）。
- 输入：该王近期 events + 当前评分；输出：可执行规划意见（文本卡）。
- 与评分系统分工：评分=客观反馈（规则），AI 意见=主观可执行建议（LLM）。

## 7. 视觉风格（新粗野主义 Neo-Brutalism）
- 特征：粗黑边框、硬阴影(offset 无模糊)、高饱和撞色、大号粗体无衬线、不圆角/少渐变、张扬反精致。
- 各"王"用**独立高饱和主色**，形成人格化辨识（薄肌王 / 力王 / 黄毛王 色板 TODO）。
- *视觉术语以 PO 确认为准；若"新粗野风格"另有所指，以 PO 解释为准。*

## 8. 用户旅程（关键路径）
1. 微信授权登录（`cloud.auth`）。
2. 首页看板：三王评分总览 + 今日待打卡。
3. 点某王 → 打卡页（手动录入该王热点数值）→ **即时评分反馈**。
4. 看板趋势 + AI 意见卡（generatePlan）。
5. 执行 → 次日再打卡，形成闭环。

## 9. MVP 功能清单（MoSCoW）
- **Must**：微信登录、三王打卡录入（手动）、评分系统、看板总览、AI 意见(LLM)、各王人格化粗野视觉。
- **Should**：趋势图、周/月报、评分等级动画。
- **Could**：导入能力（微信运动等）、社交排行、王成就体系。
- **Won't(v1)**：能力/兴趣域、复杂图可视化(ReactFlow)、实时流、Neo4j、多人协作。
